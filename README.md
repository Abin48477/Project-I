# 🌿 Ayurvedic Health Care

A web-based Ayurvedic Health Care System developed as a BCA Project-I at Tribhuvan University.

The application helps users understand their Ayurvedic body constitution (Vata, Pitta, and Kapha), provides personalized health guidance, natural remedies, and information about Ayurvedic products. It aims to promote holistic wellness by combining traditional Ayurvedic knowledge with modern web technology.

---

## 📌 Features

### User Module
- User Registration & Login
- Dosha (Vata, Pitta, Kapha) Assessment
- Personalized Health Recommendations
- Ayurvedic Remedies
- Herbal Product Information
- Product Reviews
- Contact & Feedback

### Admin Module
- Secure Admin Login
- Manage Users
- Manage Products
- Manage Dosha Information
- Manage Remedies
- View Reports
- Manage User Activities
